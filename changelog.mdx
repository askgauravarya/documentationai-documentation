<Update label="2026-08" description="v1 partner API reference" tags={["v1"]}>
## What changed

- Published the `/v1` partner API reference: workflows, runs, reviews, reports, and webhooks.
- `POST /v1/signals/{run_id}/human_review_decision` no longer accepts `payload.node_id`.
  A review decision applies to the whole run, and sending a `node_id` is now a `400` rather than an ignored field.
</Update>
